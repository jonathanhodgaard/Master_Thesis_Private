# Weather donors for 1988–1989 and 1998–1999

The overlays follow the existing July-to-July convention: 1988-07-01 to
1989-07-01 exclusive, and 1998-07-01 to 1999-07-01 exclusive. Both contain
8760 hourly snapshots. They use the full archived ERA5 cutouts, with all weather
consumers set to the selected default cutout and the existing nuclear reference.

| Overlay | Archived cutout |
| --- | --- |
| `config/config.weather_1988_89.yaml` | `europe-1986-1991-era5.nc` |
| `config/config.weather_1998_99.yaml` | `europe-1996-2001-era5.nc` |

Copy the two overlays, the batch file and the link script to their matching
locations in the Sophia repository. Then run on Sophia:

```bash
cd /work/users/s203684/projects/Master_Thesis_Private
mkdir -p logs
bash scripts/prepare_weather_1988_1998_links.sh
sbatch run_weather_donors_1988_1998.sbatch
```

The link script uses `/groups/EXTREMES/cutouts/` and verifies readable source
files. It can be rerun safely; it refuses to replace an existing destination
that points elsewhere. Override `CUTOUT_SOURCE_DIR` if the archive has moved.

The batch defaults to preparing both weather donors for `sector_2025`, producing:

```text
resources/weather_1988_89/sector_2025/networks/base_s_10___2025.nc
resources/weather_1998_99/sector_2025/networks/base_s_10___2025.nc
```

For both 2035 variants instead:

```bash
sbatch --export=ALL,WEATHER_SCENARIOS="sector_2035_w_V2G sector_2035_wo_V2G" run_weather_donors_1988_1998.sbatch
```

To build 2025 and both 2035 variants in one sequential job:

```bash
sbatch --export=ALL,WEATHER_SCENARIOS="sector_2025 sector_2035_w_V2G sector_2035_wo_V2G" run_weather_donors_1988_1998.sbatch
```

Select one weather year with `--export=ALL,WEATHER_YEARS=1988_89` (or `1998_99`).
For 2035 the output is under the selected scenario directory and ends in
`base_s_10___2035.nc`. The existing allocation is retained: one exclusive workq
node, 32 CPUs, 48 hours. Do not run overlapping preprocessing jobs concurrently.

To preview the 2025 workflow on Sophia before submitting:

```bash
source /home/s203684/miniforge3/etc/profile.d/conda.sh
conda activate "$PWD/.conda-env"
for year in 1988_89 1998_99; do
  snakemake "resources/weather_${year}/sector_2025/networks/base_s_10___2025.nc" \
    --dry-run --cores 1 \
    --configfiles config/config.sector_2025.yaml config/config.sophia.yaml \
                  "config/config.weather_${year}.yaml" || break
done
```

## Updated interconnector campaigns

The campaigns now select 1965–1966, 1968–1969, 1988–1989 and 1998–1999,
replacing 1964–1965 and 1982–1983. The 2035 arrays also include the reference
weather 2013–2014. Copy the updated configurations, campaign script and matching
batch files to Sophia before running. Keep the configuration and scripts fixed
while an array is queued or running.

2025: 32 tasks, all eight cases across the four donor years.

```bash
python -m scripts.run_disruption_campaign --check-inputs
sbatch run_disruption_array.sbatch
```

2035: 40 tasks per variant, all eight cases across the reference and four donors.
For V2G:

```bash
python -m scripts.run_disruption_campaign \
  --configfiles config/config.sector_2035_w_V2G.yaml config/config.sophia.yaml \
                config/config.interconnector_disruption.yaml \
                config/config.interconnector_disruption_2035_w_V2G.yaml \
  --years 2013-2014,1965-1966,1968-1969,1988-1989,1998-1999 --check-inputs
sbatch run_disruption_array_2035_w_V2G.sbatch
```

For without V2G, replace `w_V2G` with `wo_V2G` in the command and filename.
Submit only after the corresponding input check passes. It checks the solved
reference network, household heat shares and prepared donors. Replace
`--check-inputs` with `--list` to inspect the task mapping.

Each task retains the existing outage cases, dates, rolling settings and
infeasibility diagnostics. A failed task does not stop other array tasks. Up to
four tasks run concurrently per array. The old build overlays and result folders
are retained; the removed years are no longer selected in these campaigns.
