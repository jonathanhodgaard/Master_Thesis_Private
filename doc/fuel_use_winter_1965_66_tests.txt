Short fuel-use / hydrogen diagnostic: 2025 and 2035 without V2G
===========================================================

Run from the repository root on Sophia after copying these files there.
Both runs use 1965-1966 weather, mapped onto the reference model calendar:
January 1-29, 2014 (end-exclusive), representing January 1966 weather.
Gas/oil consuming-Link reductions apply January 8-22, with one week before
and after. Rolling horizon: 168 hours, 48-hour overlap; 672 implemented hours.

Seven cases per planning year, in array order:
0 control (base_weather)
1 gas_reduction_50
2 gas_reduction_75
3 gas_reduction_90
4 oil_reduction_50
5 oil_reduction_75
6 oil_reduction_90

Preflight in the cluster environment (does not submit a job):
  bash run_fuel_use_winter_1965_66_2025.sbatch --list
  bash run_fuel_use_winter_1965_66_2025.sbatch --check-inputs
  bash run_fuel_use_winter_1965_66_2035_wo_V2G.sbatch --list
  bash run_fuel_use_winter_1965_66_2035_wo_V2G.sbatch --check-inputs

Submit:
  mkdir -p logs
  sbatch run_fuel_use_winter_1965_66_2025.sbatch
  sbatch run_fuel_use_winter_1965_66_2035_wo_V2G.sbatch

Each array allows four concurrent single-node jobs (up to eight across both).
For the smallest first check, submit only control and gas 90%:
  sbatch --array=0,3%2 run_fuel_use_winter_1965_66_2025.sbatch
  sbatch --array=0,3%2 run_fuel_use_winter_1965_66_2035_wo_V2G.sbatch

Inputs must already exist: each planning year's solved base network and heat
shares, plus its own 1965-1966 weather donor. The 2035 run uses sector_2035_wo_V2G
inputs throughout. The preflight reports missing files; these scripts do not
build base networks or donors. Do not change --years/--cases without adjusting
the array indices. Extra arguments are passed to the campaign runner.

These runs test a higher process-hydrogen penalty. Final hydrogen/fuel demand
shedding retains its common 23300 EUR/MWh penalty. Earlier results remain in
the original *_1965_66_h2_test/ and *_1965_66_h2_50000_test/ roots
and are not overwritten.

These runs retain the current hydrogen mechanism. Penalised artificial H2
for process consumption remains enabled at 200000 EUR/MWh; synthesis minimum
outputs are preserved. They do not implement production curtailment or a
gas/biomass-dependent eligibility restriction. No biomass disruption is added.
Final hydrogen/fuel demand shedding is reported separately from process H2.
The high penalty is a sensitivity, not a rule requiring full electrolysis
utilisation or limiting artificial H2 to minimum process requirements.
After solving, inspect electrolyser headroom and synthesis minimum dispatch
during every hour with artificial process H2.

Short runs start from common reference predecessor inventories and reference
pre-January resource usage, not a continuous July-January historical dispatch.
They are screening tests rather than full-year resilience results.

Separate output roots, each followed by 1965-1966/<case>/:
  results/disruptions/sector_2025_fuel_use_winter_1965_66_h2_200000_test/
  results/disruptions/sector_2035_wo_V2G_fuel_use_winter_1965_66_h2_200000_test/

Compare each disruption with its own same-year control. Inspect:
  hydrogen_shedding_by_bus.csv and hydrogen_shedding_timeseries.csv:
    artificial process H2 usage, location, timing and penalty.
  fuel_shedding_by_fuel.csv and fuel_shedding_by_demand.csv:
    unmet final fuel demand, including final hydrogen demand.
  dispatch_summary.csv:
    hydrogen_supply_shortfall_MWh and hydrogen_shedding_cost_EUR.
  fuel_link_disruptions.csv and network_solved.nc:
    affected Links and actual SMR/electrolysis/synthesis dispatch.
