Fuel-use Link restrictions (corrected Nicoline-style campaign)
=============================================================

The default campaign now restricts consuming LINKS, not primary supply
Generators. This follows Nicoline's availability-factor approach, with an
explicit single consumption boundary to avoid also restricting supply and
transport. It is not an exact copy of her broad biomass-carrier filter.

For each fuel, choose Links whose bus0 is the raw fuel bus (gas or refined oil)
and whose bus1 is not another raw-fuel bus of the same carrier. This includes:
- Gas: CCGT, OCGT, CHP, boilers, industrial delivery (including CC), SMR.
- Oil: electricity/CHP/boilers and delivery to road transport, aviation,
  shipping, agriculture and industrial naphtha.

Supply Generators, gas/oil transport between raw-fuel buses, oil refining,
storage, and downstream accounting Links are excluded. A gas-for-industry
delivery Link is restricted once; another Link downstream of its industrial
bus is not restricted again. CHP input availability is reduced once, affecting
its electricity and heat together; efficiencies are not multiplied again.

The rule multiplies normal Link p_max_pu by (1-reduction), in [start,end).
50/75/90% capacity reductions leave 50/25/10% of the normal maximum input rate.
Outside the event normal availability applies. Nominal ratings are unchanged.
Actual consumption need not fall by the same percentage. These restrictions
limit use even when fuel is in storage; stocks cannot bypass a restricted CHP.

Configuration: config/config.fuel_use_disruption_2025.yaml, with optional
config/config.fuel_use_winter_test_2025.yaml afterward. Do NOT load the older
fuel-supply or interconnector campaign configs into this campaign.

Example event under disruption.cases.<case>:
  fuel_link_disruptions:
    - name: gas_use_75
      fuel: gas
      reduction: 0.75
      start: '2014-01-08 00:00'
      end: '2014-01-22 00:00'
      # Optional consuming-country selector: countries: [DK, DE]
      # Optional exact eligible Link names: links: [DK0 0AC CCGT]
  fuel_generator_disruptions: []

Country attribution uses the consuming bus (bus1), so country selection also
works for uses of shared EU oil. Exact Links must belong to the eligible
consumption set; selecting pipelines or refining fails validation. Overlapping
events on the same Link are rejected. Combining upstream Generator and
consuming-Link restrictions for the same fuel is rejected in either order.

Winter campaign: 2025 base; 1-29 January 2014 model calendar; event 8-22 January.
Seven cases (control + gas 50/75/90 + oil 50/75/90), four historical weather years
(1965-66, 1968-69, 1988-89, 2019-20), 28 tasks. Rolling horizon 168 h / overlap
48 h. Short test uses common reference predecessor inventories at January 1
and reference pre-January resource usage, not a donor-specific July-January
simulation. --full-year retains July initialization and continuous prehistory.
Controls and disruptions use identical starting assumptions per run mode.

From repository root:
  python -m scripts.run_fuel_use_campaign --list
  python -m scripts.run_fuel_use_campaign --check-inputs
  sbatch run_fuel_use_winter_test_2025.sbatch

Reference-weather workflow dry run:
  python -m scripts.run_fuel_use_campaign --years 2013-2014 --cases gas_reduction_90 --task-index 0 --cores 2 --dry-run

Full-year cluster campaign:
  sbatch run_fuel_use_winter_test_2025.sbatch --full-year

The previous run_fuel_supply_campaign command now redirects to these corrected
default configs for compatibility. Older explicit supply configs remain a
separate experiment; they are not loaded by either default entry point.

Results go to results/disruptions/sector_2025_fuel_use_winter_test/<year>/<case>/
or sector_2025_fuel_use_disruption for full-year runs, separate from old supply
results. fuel_link_disruptions.csv records every selected Link and restricted
input capacity. fuel_generator_disruptions.csv is empty for these cases.

Fuel shedding is capped at actual final demand and remains configurable under
load_shedding.fuel. For fixed industry/transport demands it records the missing
delivery. Electricity/heat shedding covers missing CHP/boiler/power output.
Original delivery and import capacities stay in place; no doubling or 50 GW
import override is reintroduced. Final unmet fuel cannot uniquely identify
whether a supply limit or original delivery bottleneck caused the shortfall;
compare with the same-weather control and inspect the recorded Link flows.
