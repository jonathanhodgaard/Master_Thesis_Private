# Prepare July 2019–June 2020 weather on Sophia

This replaces the failed 1998–1999 selection with 2019–2020 for 2025 and both
2035 interconnector campaigns. The retained donors are 1965–1966, 1968–1969
and 1988–1989. The 2035 arrays also retain the 2013–2014 reference year.
Existing donor/result files are retained.

Copy the package files to their matching repository folders on Sophia. Then:

```bash
cd /work/users/s203684/projects/Master_Thesis_Private
mkdir -p data/cutout/archive/v1.0 logs
ln -s /groups/EXTREMES/cutouts/europe-2016-2021-era5.nc \
  data/cutout/archive/v1.0/europe-2016-2021-era5.nc
ls -lhL data/cutout/archive/v1.0/europe-2016-2021-era5.nc
sbatch run_weather_donors_2019_2020.sbatch
```

If the link already exists, inspect it instead of replacing it. The new batch
defaults to **all three models**, built sequentially in one compute allocation.
It stops at prepared donor networks; no investment solve is requested.

To prepare a single model instead, use one of:

```bash
sbatch --export=ALL,WEATHER_SCENARIOS=sector_2025 run_weather_donors_2019_2020.sbatch
sbatch --export=ALL,WEATHER_SCENARIOS=sector_2035_w_V2G run_weather_donors_2019_2020.sbatch
sbatch --export=ALL,WEATHER_SCENARIOS=sector_2035_wo_V2G run_weather_donors_2019_2020.sbatch
```

Choose either the combined job or a selected single-model job; avoid overlapping
preparation jobs because they share preprocessing inputs.

The cutout covers 2016–2021. The selected donor covers 2019-07-01 inclusive to
2020-07-01 exclusive, with 29 February removed to match the 8760-hour reference
calendar. The validator checks the calendar and finite demand/weather profiles
after each build. It reports the first affected assets and timestamps if invalid
values exist; it never fills gaps automatically.

Outputs:

```text
resources/weather_2019_20/sector_2025/networks/base_s_10___2025.nc
resources/weather_2019_20/sector_2035_w_V2G/networks/base_s_10___2035.nc
resources/weather_2019_20/sector_2035_wo_V2G/networks/base_s_10___2035.nc
```

Check the submitted job (replace JOBID with the returned number):

```bash
sacct -j JOBID --format=JobID,JobName%30,State,ExitCode,Elapsed
tail -n 60 logs/weather_2019_2020-JOBID.out
tail -n 60 logs/weather_2019_2020-JOBID.err
```

A successful build prints `Prepared and validated:` for each selected model.

After preparation succeeds, run the normal disruption input checks with the
updated selections. To run just the replacement year's eight 2025 cases:

```bash
source /home/s203684/miniforge3/etc/profile.d/conda.sh
conda activate "$PWD/.conda-env"
python -m scripts.run_disruption_campaign --years 2019-2020 --check-inputs
sbatch --array=0-7%4 run_disruption_array.sbatch --years 2019-2020 --rerun-incomplete
```

The array override is required when selecting only one year. Standard 2025
submission still selects four donor years (32 tasks), and standard 2035
submission selects the reference plus four donors (40 tasks per variant).
Keep configuration and script versions fixed while jobs are queued or running.
